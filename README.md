# Karissa Kocourek

My personal website, built with React and Vite.

**Live site:** https://karissakocourek-dev.github.io/KarissaKocourek/

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173/KarissaKocourek/.

## Publish changes

GitHub Pages serves the site from the `docs/` folder on the `main` branch. After making changes, rebuild and commit the output:

```bash
npm run build
git add -A
git commit -m "Update site"
git push
```

The live site updates a minute or two after the push.
